# **App Name**: Mujer Web

## Core Features:

- Client Access via Token: Provide each client a unique URL token for passwordless access to their personal data.
- Appointment History: Display upcoming appointments and past appointment history for clients, including service details and color information.
- Secure Authentication: Secure authentication for admin and employee access to the backend system.
- Admin Panel: Admin panel to create, edit client profiles, manage appointment schedules, and add internal comments.
- Employee Panel: Employee panel with restricted access to view client profiles and service history.
- Auto-Generated Screens: Automatically generate all the needed screens. Firebase studio handles automatically saving of data as it is changed

## Style Guidelines:

- Primary color: Deep violet (#7957D6) for sophistication and modernity.
- Background color: Light gray (#F0F2F5) provides a clean and professional backdrop.
- Accent color: Soft lavender (#A584E5) for interactive elements and highlights.
- Body and headline font: 'Inter' sans-serif, offering a clean and modern appearance for all text.
- Use minimalist, line-style icons for services and actions.
- Design a clean and mobile-friendly layout.
- Use subtle transitions and animations to enhance user experience when navigating between views.
